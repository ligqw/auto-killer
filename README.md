# 🛡️ Auto-Killer (Автоубийца зависших программ)

Простой и легковесный `.bat` скрипт для автоматического закрытия программ, которые перестали отвечать. Идеально подходит для **старых и слабых компьютеров**, так как не нагружает процессор постоянными проверками.

## 🚀 Как запустить
1. Скачайте файл `killer.bat`.
2. Кликните по нему правой кнопкой мыши.
3. Выберите **"Запуск от имени администратора"** (это необходимо, чтобы скрипт имел права закрывать зависшие процессы).

## ⏱️ Как это работает
* Скрипт проверяет систему в фоне.
* Время ожидания до закрытия составляет **60 секунд** — это оптимальный баланс, чтобы не убить нужную программу, которая просто временно задумалась под нагрузкой.

## 🛠️ Настройка под себя
Вы можете открыть файл через обычный Блокнот и легко изменить время ожидания или добавить свои правила.
